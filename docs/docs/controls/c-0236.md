ArmoBest

## Severity

High

## Description of the the issue

Verifies the signature of each image with given public keys or trusted keyless (Fulcio) identities. Note, this control is configurable. See below the details.

## Related resources

CronJob, DaemonSet, Deployment, Job, Pod, ReplicaSet, StatefulSet

## What does this control test

Verifies the signature of each image with given public keys or trusted keyless (Fulcio) identities. An image passes if either a trusted key or a trusted identity verifies it.

## Remediation

## Configuration

This control can be configured using the following parameters. Read CLI/UI documentation about how to change parameters.

### Trusted Cosign public keys

[trustedCosignPublicKeys](../frameworks-and-controls/configuring-controls.md#trustedcosignpublickeys)  
A list of trusted Cosign public keys that are used for validating container image signatures.

### Require Cosign transparency log entry

[cosignRequireTransparencyLog](../frameworks-and-controls/configuring-controls.md#cosignrequiretransparencylog)  
Whether a valid signature must also have a transparency log (Rekor) entry. Set to `false` to accept images signed with `--tlog-upload=false`.

### Cosign Rekor URL

[cosignRekorURL](../frameworks-and-controls/configuring-controls.md#cosignrekorurl)  
URL of the Rekor transparency log used to look up signatures that have no Rekor bundle.

### Trusted Cosign keyless identities

[trustedCosignIdentities](../frameworks-and-controls/configuring-controls.md#trustedcosignidentities)  
Keyless (Fulcio) signers to trust, each an OIDC issuer regular expression and a certificate identity regular expression.
